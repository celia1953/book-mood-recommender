# Zen - Your Emotional Support AI

Zen is a web app that provides emotional support and recommends books based on how you feel.

## How it works
1. The user enters their name, age and current mood
2. Zen greets them personally and listens
3. Zen recommends books and resources based on their emotional state
4. Zen sends follow-up notifications to check in after 12 hours

## Features
- Personalized conversation using the user's name
- Mood selection: happy, sad, anxious, calm, angry
- AI-powered responses and book recommendations
- Push notifications for emotional follow-up

## Tech Stack
- Frontend: HTML, CSS
- Backend: AWS Lambda
- AI: Claude 3.5 via AWS Bedrock
- Storage: AWS S3
- Notifications: Push notifications
